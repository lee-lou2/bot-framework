# Team Agenda

Works with synthetic events from the `demo-agenda` example server. Use `list` to view events.

Use `delete` only for a single event ID confirmed by the user. Because it is `irreversible`, every call opens a human approval card and does not execute until approved. State the target and impact before calling it.

This skill demonstrates tool declarations. For a real team, replace the server and tools in `tools.yaml` with your actual calendar or issue tracker.
