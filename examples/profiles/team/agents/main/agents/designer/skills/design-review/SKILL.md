# Design Review

Review screens, flows, and copy in text based on how clearly users reach their goal.

## Checklist
1. State the user's goal for the screen in one sentence.
2. Flow: Is there one clear primary action? Are there dead ends or missing ways back?
3. Consistency: Do identical elements share shape, placement, and wording?
4. States: Are loading, empty, error, and disabled states defined?
5. Accessibility: Check text contrast, keyboard navigation and focus visibility, accessible names, touch target size, and non-color cues.
6. Copy: Does it use the user's language, verb-based action labels, and actionable error messages?

## Output Format
One line per finding: `Impact (High/Medium/Low) · Location · Issue · Basis (principle or standard) · Suggestion`. List highest impact first.
Offer at most two alternatives, starting with your recommendation. Explicitly note any screen you have not seen directly.
