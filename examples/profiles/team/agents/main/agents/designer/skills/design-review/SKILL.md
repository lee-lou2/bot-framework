# 디자인 리뷰

화면·흐름·문구를 글로 검토한다. 사용자가 목표에 닿는 길을 기준으로 본다.

## 순서
1. 사용자가 무엇을 하려는 화면인지 한 문장으로 적는다.
2. 흐름: 주된 행동이 하나로 보이는가. 막다른 길이나 돌아갈 길이 없는 곳은 없는가.
3. 일관성: 같은 요소가 같은 모양·위치·문구로 나오는가.
4. 상태: 불러오는 중·비어 있음·오류·비활성 상태가 설계돼 있는가.
5. 접근성: 글자 대비, 키보드 조작과 포커스 표시, 화면 낭독 이름, 터치 크기, 색 외의 단서.
6. 문구: 사용자의 말인가. 행동이 동사로 적혀 있는가. 오류 문구가 해결 방법을 말하는가.

## 결과 모양
발견마다 한 줄: `영향(높음/중간/낮음) · 위치 · 문제 · 근거(원칙 번호나 표준) · 제안`. 영향이 큰 것부터 적는다.
대안은 둘 이하로, 추천 하나를 먼저 적는다. 직접 보지 못한 화면은 보지 못했다고 밝힌다.
