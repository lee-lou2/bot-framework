# 팀 소개(예시)

이 문서는 합성 예시다. 실제 팀의 내용으로 바꿔 쓴다.

## 팀과 역할
- 팀 이름: 오차드. 가상의 모바일 메모 앱을 만드는 네 사람의 팀이다.
- alice: 기획(PM). 요구사항과 우선순위를 정한다.
- bob: 개발. 앱과 서버 코드를 만든다.
- carol: 디자인. 화면과 사용 흐름을 만든다.
- dave: 운영. 배포와 장애 대응을 맡는다.

## 일하는 리듬
- 평일 09:00(Asia/Seoul)에 팀 요약을 받는다. `main`의 `standup` 트리거가 만든다.
- 릴리스는 매주 목요일 오후에 한다. 금요일에는 배포하지 않는다.
- 코드 리뷰는 요청한 뒤 하루 안에 첫 의견을 낸다.
- 일정과 우선순위는 월요일 아침에 한 번 맞춘다.
